MODEL EVIDENCE

How should we trust the estimates?

Review error metrics and candidate-model benchmarks before interpreting predictions. Price is more predictable than DOM in this run. DOM has missing values and a strongly skewed target; its MAE is about 18 days and R² is about 0.46, so treat it as a rough estimate. R² is not accuracy percentage, and no metric guarantees an individual result.
